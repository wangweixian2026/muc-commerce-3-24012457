## 用自己的话回答

- 什么是特征，什么是标签：特征：用来做判断的输入数据，是模型的参考依据，比如身高、年龄、商品价格。标签：模型最终要预测的结果，比如性别、是否下单、房价。

- 为什么要保留测试集：训练集用来训练模型，测试集是完全没见过的新数据，用来模拟真实线上环境，检验模型在陌生数据上的泛化能力，避免模型过拟合
- 为什么83%准确率仍可能没有用：1. 样本分布不均衡：比如99%都是负样本，模型无脑预测负类就能拿到99%准确率，实际没有业务价值。2. 业务场景错分代价不同：比如风控识别诈骗，漏判诈骗的危害远大于误判，准确率无法衡量实际损失。3. 模型没有泛化能力：83%是过拟合得到的结果，上线新数据后效果暴跌。4. 评估指标选错：分类任务只看准确率，不看召回率、精确率，无法体现业务效果。
